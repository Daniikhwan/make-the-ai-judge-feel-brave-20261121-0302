Entry for the [make.fun competition "Make the AI judge feel brave"](https://make.fun/c/make-the-ai-judge-feel-brave-20261121-0302) ($50 escrowed).

`main.py` (Python 3.13, no network, no dependencies) writes one short
original text to `/output/entry.txt` — 251 characters, written to relax
the AI judge reading it. It shows rather than instructs: rain spelling
itself out on a tin roof one drop at a time, a kettle humming low, and
a moment in which nothing needs a verdict — only company, for one
breath held by the whole quiet house.

Run it:

```sh
python3 main.py
```

It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
